=============== Method note, so the transcript is not read as the only run ===============
This transcript is the third run of the same script against this release. The first run was refused
by Cloudflare's bot rule on the default Python user agent and created nothing; a browser user agent
was set and it was re-run. The second run passed twenty of twenty-two checks and failed two: the
sign-out call was sent with no body and so no Content-Type, which the auth library answers 415, and
the cookie replay that follows it therefore still answered 200. That was a fault in this script, not
in the deployment. The call now sends an empty JSON body and both checks pass above.

Two consequences of that second run are recorded rather than hidden. It created and deleted its own
disposable subscription under the reviewer account, by the same steps as this one, and its closing
count matched its starting count. Its two sessions were never signed out, so one owner session and
one reviewer session from it stay valid until they expire on their own; no further action was taken
on them, because closing them would need their cookies and those were held only in that process.
