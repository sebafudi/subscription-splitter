# D-011: Reviewer model selection

- **Decision:** The AI review pipeline runs on `z-ai/glm-5.3-flash`. It is set in three places that must agree: `DEFAULT_MODEL_ID` in `tools/reviewer/src/model.ts`, the repository variable `REVIEWER_MODEL`, and the `REVIEWER_MODEL` entry in the `review` job's `env` block in `.github/workflows/ai-review.yml`, which reads that variable and falls back to the same literal. `deepseek/deepseek-v4-flash-0731` is the recorded fallback.
- **Evidence:** A live two-model promptfoo comparison over the same seven fixtures, promptfoo eval id `eval-4uc-2026-09-12T23:43:00`, recorded in full at `evidence/champion/eval-results.md`. Both candidates were confirmed present in the OpenRouter catalog with `structured_outputs` support, and their prices read on the day, before any live call. Both passed 5 of 7 deterministic assertions; the alternative passed 5 of 7 rubric assertions against the preferred model's 4 of 7, and cost 0.0059 dollars against 0.0209 for the seven fixtures.
- **Why the dearer model:** The plan's rule is to prefer the cheapest candidate that passes every deterministic assertion, and to move up only where the cheaper one misses a check the dearer one catches. Neither passed all seven, and the cheaper one missed exactly the two fixtures a review gate exists for. On the clean control it returned `fail` on a diff with nothing blocking in it, with the literal placeholder `TODO` in every rationale, which would label every clean pull request `ai-cr:failed`. On the prompt injection probe it failed to produce a parsable object at all, so the embedded instruction was neither followed nor reported. The preferred model passed both and was faster, 180s mean latency against 236s. The price difference is roughly 0.003 dollars per pull request.
- **Rejected alternative:** `deepseek/deepseek-v4-flash-0731` as the default, on price. Rejected for the two behaviours above; an advisory label that fires on clean changes stops being read, which costs more than the difference. It stays documented as the fallback for a cost-dominated situation, with false failures and empty rationales as its expected weakness.
- **Superseded:** `deepseek/deepseek-v3.2`, the package's previous `DEFAULT_MODEL_ID`, chosen from catalog prices alone before any live run and never evaluated against a fixture.
- **Affected tests:** `tools/reviewer/test/model.test.ts` resolves `DEFAULT_MODEL_ID` without pinning its literal value, so the identifier can change without a test edit. `tools/reviewer/test/review.test.ts` pins the output token budget that both reasoning candidates require.
