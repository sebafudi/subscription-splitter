# D-003: AI review pipeline route and model access

- **Decision:** The module 5 (Champion) evidence route is the CI code-review pipeline: an independent reviewer package in `tools/reviewer/` built with the Vercel AI SDK (provider-agnostic), five review criteria with a structured verdict schema, promptfoo evaluation of two or three models on fixed diff fixtures, and a GitHub Actions workflow that posts the review as a PR comment. The artifact-registry project is not pursued.
- **Provider strategy:** All model access goes through OpenRouter (`@openrouter/ai-sdk-provider` with the Vercel AI SDK; promptfoo `openrouter:` provider for evaluations). The reviewer takes the model ID from configuration so the promptfoo comparison and the CI run use the same package. The credential is `OPENROUTER_API_KEY`, provided locally through the shell environment or `tools/reviewer/.env` (ignored by Git, loaded automatically by the CLI's `main()` via `process.loadEnvFile` when the file is present) and in CI as a GitHub Actions secret; it is never committed. Spending is bounded: small fixed diffs, capped output tokens, one retry, and the eval matrix run only when prompts change. Local pipeline code, prompts, schema, fixtures and CI wiring are prepared independently of the credential.
- **Fallback:** An established review action with custom configuration (accepted by the organizers) remains available if SDK integration is blocked by credentials. Using it would leave the SDK spike and eval exercises unperformed; those items stay open and are reported as such rather than marked complete.
- **Security constraints:** PR text and diffs are untrusted input. The workflow runs with read-only repository permission plus pull-request write for the comment, bounded diff size, bounded tokens and retries, no shell execution of PR code, and no secrets exposed to the model. Fork PRs do not receive privileged credentials.
- **Rejected alternative:** Building a shared skill/agent registry (M5L4). Rejected because the review pipeline exercises the SDK, evaluation and CI skills the course teaches and produces the required screenshots directly.
- **Affected tests:** `tools/reviewer` unit tests for schema validation and malformed-output handling; promptfoo fixtures as a regression gate.
- **Commit:** recorded when `tools/reviewer` lands.
